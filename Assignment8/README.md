# MemoMind: AI 기반 노트 앱

MemoMind는 생각을 정리하고, 아이디어를 기록하며, 중요한 정보를 관리하는 데 도움을 주는 지능형 노트 애플리케이션입니다. 

## ✨ 주요 기능

- **✍️ 서식 있는 텍스트 편집**: 마크다운 문법을 지원하는 텍스트 에디터로 생각을 구조화할 수 있습니다.
- **🗂️ 체계적인 정리**: 카테고리와 태그를 사용하여 노트를 유연하게 분류하고 관리할 수 있습니다.
- **🎨 사용자 맞춤 테마**: 노트 색상과 우선순위(높음, 중간, 낮음)를 설정하여 중요한 노트를 쉽게 구분할 수 있습니다. 사이드바 색상도 자유롭게 변경하여 나만의 분위기를 연출할 수 있습니다.
- **🧠 AI 요약 기능**: Genkit과 Gemini 모델을 활용하여 긴 노트의 핵심 내용을 버튼 클릭 한 번으로 요약할 수 있습니다.
- **🔍 빠른 검색 및 필터링**: 제목, 내용, 태그, 카테고리별로 노트를 즉시 검색하고 필터링할 수 있습니다.
- **💾 로컬 저장소**: 모든 데이터는 브라우저의 로컬 저장소에 안전하게 저장되어 개인 정보 보호를 보장합니다. 별도의 서버 없이 오프라인에서도 작동합니다.
- **📱 반응형 디자인**: 데스크톱과 모바일 환경 모두에서 완벽하게 작동하는 반응형 UI를 제공합니다.

## 🛠️ 기술 스택

- **프레임워크**: Next.js (App Router)
- **UI**: React, TypeScript, Tailwind CSS
- **UI 컴포넌트**: shadcn/ui
- **AI 통합**: Google Genkit (Gemini 모델)
- **상태 관리**: React Hooks (Custom Hooks)
- **폼 처리**: React Hook Form, Zod
- **아이콘**: Lucide React

## 🚀 시작하기

1. **종속성 설치**:
   ```bash
   npm install
   ```

2. **개발 서버 실행**:
   ```bash
   npm run dev
   ```

3. 브라우저에서 [http://localhost:9002](http://localhost:9002)를 엽니다.

## 🤖 AI 기능 설정

AI 요약 기능을 사용하려면 Google AI Studio에서 API 키를 발급받아 프로젝트 루트에 `.env` 파일을 생성하고 다음과 같이 키를 추가해야 합니다.

```
GEMINI_API_KEY=여러분의_API_키를_여기에_입력하세요
```
